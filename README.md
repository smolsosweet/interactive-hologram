# Interactive Solar System Hologram 🌌

A highly interactive 3D Solar System application built with **Three.js** and **MediaPipe Hands**. This project is optimized to run as a full-screen, borderless window on a holographic prism display.

## Key Features
- **True Holographic Aesthetic:** Deep black backgrounds and high-contrast, glowing UI elements for seamless pyramid reflection.
- **Hand Gesture Control (AI):** No keyboard/mouse required. Uses MediaPipe AI bone-structure recognition to track hands in real time.
- **Dynamic 3D Models:** Physically accurate models of the Sun and all 8 planets, supporting panning, rotation, and zooming.

## Getting Started
1. Install dependencies: `npm install`
2. Start the application: `npm start`
3. Bring your hands in front of the webcam to interact!
